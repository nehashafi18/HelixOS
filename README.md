# HelixOS — Genetic Variant Analysis Platform

AI-powered genomic variant interpretation platform that uses machine learning and conversational AI to help researchers analyze and understand genetic mutations.

> **Research use only.** Not a clinical diagnostic tool. All predictions should be reviewed by a qualified clinician.

---

## What it does

HelixOS analyzes genetic variants (amino acid substitutions) and predicts their pathogenicity using a Random Forest model trained on ClinVar data. Each prediction is explained in plain language using biological context, SHAP feature attribution, and an AI research assistant powered by Claude.

### Features

- **Variant analysis** — Upload CSV/Excel files, get pathogenicity predictions with confidence scores
- **Biological interpretation** — Biochemical property changes (hydrophobicity, charge, polarity, size) explained in plain language
- **SHAP analysis** — Feature contribution scores show which properties drove each prediction
- **Research Assistant** — Claude-powered chat for asking questions about variants, genes, and results
- **Accessible Summary** — Plain-language report view with read-aloud support
- **Analytics dashboard** — Charts for top genes, pathogenicity distribution, confidence scores, and feature importance
- **Demo Library** — 6 synthetic datasets for exploring the platform without uploading your own data
- **PDF export** — Download full reports or individual variant reports
- **Reading level selector** — AI explanations adapt from Simple to Technical
- **Dark/light mode**, high contrast, large text accessibility options

## Running locally

### Prerequisites
- Python 3.11+
- Node.js 18+
- Anthropic API key

### Backend
```bash
cd genetic_mutations_predictor/geneinsight/backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# Create .env
echo "ANTHROPIC_API_KEY=your_key_here" > .env
echo "SECRET_KEY=any_random_string" >> .env

uvicorn main:app --reload --port 7001
```

### Frontend
```bash
cd genetic_mutations_predictor/geneinsight/frontend
npm install
npm run dev
# Opens at http://localhost:5173
```

## ML model

The Random Forest classifier is trained on ClinVar variant data using these features:

- **HydrophobicityChange** — change in amino acid water-interaction score
- **ChargeChange** — change in electrical charge
- **PolarityChange** — change in polarity
- **SizeChange** — change in side-chain size
- One-hot encoded original/mutant amino acid and variant type

SHAP values are computed per-prediction to explain which features drove the result.

> `model.pkl` (481MB) and `variant_summary.txt.gz` (419MB) are not tracked in git due to GitHub's 100MB file size limit.
